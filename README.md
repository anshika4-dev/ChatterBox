## ⚙️ Setup

### Prerequisites
Make sure you have:
- Node.js
- npm

### Installation

1. Clone the repository
2. Navigate to the project folder
3. Install dependencies

```bash
npm install
```

4. Create a `.env` file and configure the required environment variables:
   - APPWRITE_URL
   - PROJECT_ID
   - DATABASE_ID
   - STORAGE_ID
   - USER_COLLECTION_ID
   - POST_COLLECTION_ID
   - SAVES_COLLECTION_ID

5. Start the development server

```bash
npm start
```

6. Open your browser at

```bash
http://localhost:3000
```
